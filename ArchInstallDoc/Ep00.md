# Ep00. live 环境：这就是ICU？

> cSpell:disable

**live 环境**是指从安装介质（如 USB 启动盘）启动的临时操作系统环境，通常用于安装或修复系统。在 live 环境中，用户可以访问大部分系统功能，而无需实际安装操作系统到硬盘上。

## 进入 BIOS/UEFI 设置界面

```bash
# 在 Windows 中进入 BIOS (需要管理员权限)
shutdown /r /fw /t 0
# 在 Linux 中进入 UEFI 固件设置界面
systemctl reboot --firmware-setup

# 验证引导模式
cat /sys/firmware/efi/fw_platform_size
# 如果命令结果为 64，则系统是以 UEFI 模式引导且使用 64 位 x64 UEFI
ls /sys/firmware/efi
# 如果目录存在，则系统是以 UEFI 模式引导

# 安装一个终端文件查看器
pacman -S yazi
```

## 配置网络

```bash
ip link              # 确认无线网卡是否被识别
systemctl status iwd # 确认 iwd 服务正在运行
systemctl start iwd  # 启动 iwd 服务（如果未运行）

# 使用 iwctl 连接 Wi-Fi
iwctl # 进入 iwctl 交互式命令行界面
# 在 iwctl 提示符下执行以下命令
device list          # 列出所有网络设备
station <设备名称> scan    # 扫描可用的 Wi-Fi 网络
station <设备名称> get-networks  # 列出扫描到的 Wi-Fi 网络
station <设备名称> connect <网络名称>  # 连接到指定的 Wi-Fi 网络
exit # 退出 iwctl

# 验证网络连接
ping www.baidu.com -c 5

# 同步时间
timedatectl            # 确认 systemd-timesyncd 服务正在运行
systemctl set-ntp true # 如果没有运行，启动该服务

# NetworkManager 操作
systemctl enable --now NetworkManager                    # 启动 NetworkManager 服务
nmcli device wifi connect "WiFi名称" password "WiFi密码" # 通过 NetworkManager 连接 Wi-Fi
nmcli device status                                      # 查看连接状态

# 通过 nmtui 连接 Wi-Fi
nmtui
```

## SSH 远程登录设置

配置 SSH 服务，允许通过 `<用户名>@<主机名或 IP 地址>` 远程登录系统

```bash
# 进行 ssh 连接前先配置好密码

# 安装 OpenSSH 服务器
pacman -S openssh
# 启动并设置开机自启 SSH 服务
systemctl enable --now sshd

# 默认无法使用 root 用户通过 SSH 登录
# 需要先修改配置文件
# 允许指定用户通过 SSH 登录
echo "AllowUsers jElee" >> /etc/ssh/sshd_config
vim /etc/ssh/sshd_config
# 修改以下内容:
# PermitRootLogin prohibit-password
# ↓
# PermitRootLogin yes

# 重启 SSH 服务或者重启系统使配置生效
systemctl restart sshd

# 安装 mDNS 支持（avahi）
# 让主机名可以自动通过 .local 被发现
pacman -S avahi nss-mdns
systemctl enable --now avahi-daemon
# 编辑 /etc/nsswitch.conf 文件:
#
# hosts: mymachines resolve [!UNAVAIL=return] files myhostname dns
# ↓
# hosts: files mdns_minimal [NOTFOUND=return] resolve mymachines myhostname dns
#
# 说明：
# files：优先查 /etc/hosts
# mdns_minimal：允许 .local 主机名通过 mDNS（Avahi）解析
# [NOTFOUND=return]：若 mDNS 成功解析则不继续向后查找
# resolve：systemd-resolved
# mymachines / myhostname：本地 systemd 名称服务
# dns：普通 DNS 解析
```

## 配置代理

确保命令行和依赖环境变量的程序能走代理

影响所有用户的命令行工具和许多依赖 Shell 环境变量的程序

但是不影响一些图形界面程序，特别是那些使用 NetworkManager 管理网络设置的程序。

1. 临时配置（当前终端会话有效，关闭终端失效）

```bash
export http_proxy="http://i-ka.local:10811"              # HTTP 代理
export https_proxy="http://i-ka.local:10811"             # HTTPS 代理
export all_proxy="socks5://i-ka.local:10810"             # SOCKS5 代理

export proxy_url="http://i-ka.local"                            # 代理服务器地址
export proxy_port_http="10811"                                  # HTTP 代理端口
export proxy_port_socks5="10810"                                # SOCKS5 代理端口
export http_proxy="${proxy_url}:${proxy_port_http}"             # HTTP 代理
export https_proxy="${proxy_url}:${proxy_port_http}"            # HTTPS 代理
export all_proxy="socks5://${proxy_url}:${proxy_port_socks5}"   # SOCKS5 代理
export no_proxy="localhost,127.0.0.1,*.local,"                  # 不使用代理的地址列表
# 说明:
# i-ka.local 是代理服务器的主机名，10811 和 10810 是局域网代理端口
#
# 取消代理设置
unset http_proxy
unset https_proxy
unset all_proxy
unset no_proxy
unset http_proxy https_proxy all_proxy no_proxy HTTP_PROXY HTTPS_PROXY ALL_PROXY NO_PROXY
# 因为是临时配置，关闭当前终端会话代理就会自动失效

# 测试连接
curl -I https://www.google.com
```

2. 永久配置（对所有用户生效）

在 Arch 中设置系统级代理（对所有用户生效）

创建或编辑全局环境变量文件 `/etc/profile.d/proxy.sh`

写入以下内容:

**注意大小写**

`/etc/profile.d/proxy.sh`

```sh
vim /etc/profile.d/proxy.sh

# --- /etc/profile.d/proxy.sh: 全局代理配置 ---

# 配置代理地址
proxy_url="i-ka.local"                          # 代理服务器地址
proxy_port_http="10811"                         # HTTP 代理端口
proxy_port_socks5="10810"                       # SOCKS5 代理端口
no_proxy_list="localhost,127.0.0.1,*.local,"    # 排除地址列表

# 代理设置（小写变量）
export http_proxy="http://${proxy_url}:${proxy_port_http}"
export https_proxy="http://${proxy_url}:${proxy_port_http}"
export all_proxy="socks5://${proxy_url}:${proxy_port_socks5}"
export no_proxy="${no_proxy_list}"

# 代理设置（大写变量）(兼容某些程序)
export HTTP_PROXY="http://${proxy_url}:${proxy_port_http}"
export HTTPS_PROXY="http://${proxy_url}:${proxy_port_http}"
export ALL_PROXY="socks5://${proxy_url}:${proxy_port_socks5}"
export NO_PROXY="${no_proxy_list}"

# -----------------------------------------------
```

应用配置:

`bash`

```bash
# 确保脚本文件具有执行权限
chmod +x /etc/profile.d/proxy.sh
# chmod (Change Mode): 改变权限的命令
# 在 Linux 中，每个文件都有三组权限：用户 (Owner)、群组 (Group)、其他 (Others)
# 权限包括读 (r)、写 (w)、执行 (x)
# 例如，chmod +x 表示添加执行权限
# 只有为 proxy.sh 脚本添加了 +x 权限后，系统在用户登录时才会运行它
#
# /etc/profile.d/proxy.sh: 一个特殊的系统目录
# 在大多数现代 Linux 发行版中，/etc/profile 文件（系统 Shell 启动脚本）会检查这个目录下的 所有可执行脚本
#
# 当用户登录时，系统会运行 /etc/profile
# /etc/profile 文件的一个主要任务是遍历 /etc/profile.d/ 目录，并 执行 (source) 目录下的 所有可执行脚本（通常是 .sh 文件）

# 立即生效
source /etc/profile.d/proxy.sh

# 测试连接
curl -I https://www.google.com
```

## 硬盘分区

```bash
# 查看硬盘分区情况
lsblk -pf
# 查看硬盘设备信息
fdisk -l path/to/device

##############################
########## 创建分区 ##########
##############################
cfdisk /dev/sda

# 创建两个分区:
# EFI 分区(100MB)
# / 分区(剩余全部空间)

# 格式化分区
# -F 32 指定 FAT32 文件系统
mkfs.fat -F 32 /dev/启动分区    # 把 ESP(EFI 系统分区) 格式化为 FAT32 文件系统
mkfs.btrfs /dev/根分区          # 把根分区格式化为 btrfs 文件系统


##############################
########## 创建子卷 ##########
##############################

# 通过创建子卷来划分 btrfs 分区的不同用途
# 比如把系统文件和用户数据分开存放

# 挂载根分区
# -t 指定文件系统类型
# -o 指定挂载选项
# compress=zstd 表示使用 zstd 透明压缩算法
mount -t btrfs -o compress=zstd /dev/根分区 /mnt

# 创建了三个子卷: `@`, `@home`, `@swap`
# @ 表示根目录
btrfs subvolume create /mnt/@       # 根子卷
btrfs subvolume create /mnt/@home   # home 子卷
btrfs subvolume create /mnt/@swap   # swap 子卷

btrfs subvolume delete /mnt/@swap   # 如果不需要 swap 分区的话，可以删除 swap 子卷

# 为了把子卷挂载为根目录，需要先卸载根分区
umount /mnt

# 正式挂载
# 挂载根目录
# -t btrfs 指定文件系统类型为 btrfs
# -o 指定挂载选项
# subvol=@ 指定挂载 @ 子卷
mount -t btrfs -o compress=zstd,subvol=@ /dev/根分区 /mnt                   # 挂载根子卷
mount --mkdir -t btrfs -o compress=zstd,subvol=@home /dev/根分区 /mnt/home  # 挂载 home 子卷，由于 /mnt/home 目录可能不存在，使用 --mkdir 选项自动创建
mount --mkdir -t btrfs -o compress=zstd,subvol=@swap /dev/根分区 /mnt/swap  # 如果需要 swap 分区的话
mount --mkdir /dev/启动分区 /mnt/efi                                        # 挂载 ESP(EFI 系统分区)，即启动目录

# 查看挂载情况
df -h

# 查看 fstab 文件内容
cat /etc/fstab
```

# 更新系统

```bash

# 设置镜像源
# 使用 reflector 工具生成新的镜像列表
# -a 12 -> 选择最近 12 小时内同步过的镜像
# -c cn -> 选择中国的镜像
# -f 10 -> 选择最快的 10 个镜像
# --sort score -> 按照综合评分排序
# --v -> 显示详细信息
# --save -> 保存到指定文件
reflector -a 12 -c cn -f 10 --sort score --v --save /etc/pacman.d/mirrorlist

vim /etc/pacman.d/mirrorlist
# 更换为清华大学开源软件镜像站: Server = https://mirrors.tuna.tsinghua.edu.cn/archlinux/$repo/os/$arch

# 更新 pacman 用来验证软件包“真实性与完整性”的 GPG 密钥环，以避免后续安装失败
pacman -Sy archlinux-keyring


##########################
######## 安装系统 ########
##########################

# pacstrap 命令用于安装 Arch Linux 基础系统到指定的挂载点
# -K 表示复制主机的密钥环
# base -> 基础系统包
# base-devel -> 基础开发包
# linux-zen ->  Linux 性能优化内核
# linux-firmware ->  Linux 固件包
# btrfs-progs ->  btrfs 文件系统工具包
pacstrap -K /mnt base base-devel linux-zen linux-firmware btrfs-progs
# 安装必要的功能性软件包
# networkmanager -> 网络管理工具
# vim -> 文本编辑器
# sudo -> 提升权限工具
# intel-ucode -> Intel CPU 微码更新
pacstrap -K /mnt networkmanager vim sudo intel-ucode

pacstrap -K /mnt base base-devel linux-zen linux-firmware btrfs-progs networkmanager vim sudo intel-ucode


# 创建 swap 文件
# btrfs 文件系统创建 swap 文件的命令
# --size 指定 swap 文件大小
# --uuid 表示 swap 文件的 UUID
# clear 表示清除文件内容
# /mnt/swap/swapfile 指定 swap 文件的路径
btrfs filesystem mkswapfile --size 8G --uuid clear /mnt/swap/swapfile
# 启用 swap 文件
swapon /mnt/swap/swapfile


# 生成 fstab 文件，让机器启动时自动挂载分区
# -U 表示使用 UUID 方式生成 fstab 文件
genfstab -U /mnt > /mnt/etc/fstab
# 查看生成的 fstab 文件内容
cat /mnt/etc/fstab
# 应有 3 个挂载点: /, /home, /efi


##################################
######### 进入新系统环境 #########
##################################

arch-chroot /mnt

# root 密码设置
passwd

# 设置主机名
echo "Aris" > /etc/hostname

# 设置时区
# 创建链接: /etc/localtime 指向 上海 时区文件
# -s 表示创建符号链接
# -f 表示强制覆盖已存在的文件
ln -sf /usr/share/zoneinfo/Asia/Shanghai /etc/localtime
# 设置时区
timedatectl set-timezone Asia/Shanghai
# 同步硬件时钟
hwclock --systohc
# 查看时间设置
timedatectl
# 启用网络时间同步
timedatectl set-ntp true

# 网络管理服务启动并设置开机自启
# enable -> 设置开机自启服务
# --now 表示立即启动服务
systemctl enable --now NetworkManager


# 本地化设置
vim /etc/locale.gen
# 取消注释: en_US.UTF-8 UTF-8 和 zh_CN.UTF-8 UTF-8
locale-gen # 生成本地化文件

# 设置语言环境(全局本地化)
echo "LANG=en_US.UTF-8" > /etc/locale.conf
# 或者
echo "LANG=zh_CN.UTF-8" > /etc/locale.conf


##############################
######## 安装引导程序 ########
##############################

# grub -> 引导加载程序
# efibootmgr -> EFI 启动管理工具
pacman -S grub efibootmgr

# 安装 GRUB 到 EFI 分区
# --target 指定目标架构
# --efi-directory 指定 EFI 分区挂载点
# --boot-directory 指定 GRUB 文件存放目录
# --bootloader-id 指定引导加载程序标识
grub-install --target=x86_64-efi --efi-directory=/efi --boot-directory=/efi --bootloader-id=BootAyuri
# 由于部分软件默认 grub 安装路径为 /boot/grub，需要创建符号链接
ln -s /efi/grub /boot/grub

# 生成 GRUB 配置文件
# 会扫描系统中的操作系统并生成启动菜单
# -o 指定输出文件路径
grub-mkconfig -o /boot/grub/grub.cfg


############################
###### 配置双系统启动 ######
############################

# os-prober -> 操作系统探测器，帮助 GRUB 识别其他操作系统
# exfat-utils -> exFAT 文件系统工具包，支持 exFAT 格式分区，帮助找到 Windows 的 EFI 分区
pacman -S os-prober exfat-utils

# 编辑 GRUB 源文件
vim /etc/default/grub
# 修改以下内容:
#
# 添加: GRUB_DISABLE_OS_PROBER=false # 允许 GRUB 引导其他操作系统
# 添加: GRUB_SAVEDEFAULT=true        # 记住上次启动的操作系统，下次默认启动该系统
# 修改: GRUB_DEFAULT=saved           # 设置默认启动项为上次启动的系统
#
# GRUB_CMDLINE_LINUX_DEFAULT="loglevel=3 quiet"
# ↓
# GRUB_CMDLINE_LINUX_DEFAULT="loglevel=5 nowatchdog modprobe.blacklist=iTCO_wdt"
#
# 说明:
# 删除 quiet -> 取消静默模式，显示更多启动信息
# loglevel=5 -> 设置内核日志级别为 5，显示更多的信息，便于调试，最高级别为 7
# nowatchdog -> 禁用内核看门狗，防止系统自动重启
# modprobe.blacklist=iTCO_wdt -> 禁用 Intel TCO 看门狗驱动，防止系统自动重启

# 重新生成 GRUB 配置文件，使更改生效
grub-mkconfig -o /boot/grub/grub.cfg
```
