## 配置系统

```bash
sudo pacman -Syu

# 安装 fastfetch lolcat cmatrix
# fastfetch -> 系统信息显示工具
# lolcat -> 彩虹文字显示工具
# cmatrix -> 矩阵雨屏幕特效
pacman -S fastfetch lolcat

# 安装 htop 交互式进程查看器
pacman -S htop

# 桌面环境
pacman -S gnome

# 安装组件
# gnome-desktop -> GNOME 桌面环境基础组件
# gdm -> GNOME 显示管理器
# ghostty -> 终端仿真器
# gnome-control-center -> GNOME 控制中心
# gnome-software -> GNOME 软件管理器
# flatpak -> 应用程序打包和分发系统
# xdg-desktop-portal-gnome -> GNOME 桌面门户服务
pacman -S gnome gnome-desktop gdm ghostty gnome-control-center gnome-software flatpak xdg-desktop-portal-gnome

# 安装密码和密钥管理相关组件
# gnome-keyring -> GNOME 密钥环，用于存储密码和密钥
# libsecret -> 用于访问密码和密钥的库
sudo pacman -S gnome-keyring libsecret
# 启动并设置开机自启 GNOME Keyring 服务
systemctl --user enable --now gnome-keyring-daemon.service

# 启动并设置开机自启 GDM 服务
systemctl enable --now gdm
# 关闭图形界面登录
systemctl disable --now gdm
# 单次关闭
systemctl stop gdm

# 安装 Xorg 相关组件
sudo pacman -S xorg-server xorg-apps xorg-xinit
# 对于 GNOME on Xorg 会话，在 ~/.xinitrc 中添加
# export XDG_SESSION_TYPE=x11
# export GDK_BACKEND=x11
# exec gnome-session

# 删除不需要的软件包
pacman -Rns xorg-server xorg-apps xorg-xinit

# 安装字体
pacman -S ttf-sarasa-gothic # 思源黑体
pacman -S noto-fonts-emoji # 谷歌 Noto Emoji 字体

# Noto CJK 字体（支持中日韩字符）
pacman -S noto-fonts-cjk

# 一次性安装多个字体包
# sudo pacman -S ttf-sarasa-gothic noto-fonts-emoji noto-fonts-cjk

# MesloLGS Nerd Font
mkdir -p ~/.local/share/fonts
cd ~/.local/share/fonts
wget https://github.com/romkatv/powerlevel10k-media/raw/master/MesloLGS%20NF%20Regular.ttf
wget https://github.com/romkatv/powerlevel10k-media/raw/master/MesloLGS%20NF%20Bold.ttf
wget https://github.com/romkatv/powerlevel10k-media/raw/master/MesloLGS%20NF%20Italic.ttf
wget https://github.com/romkatv/powerlevel10k-media/raw/master/MesloLGS%20NF%20Bold%20Italic.ttf
fc-cache -fv
```

## Yay - AUR 助手

Yay 是一个流行的 AUR 助手，用于简化从 Arch User Repository (AUR) 安装和管理软件包的过程

```bash
# 安装 Yay
# 安装依赖
pacman -S git base-devel
# 克隆 Yay 仓库
git clone https://aur.archlinux.org/yay.git
cd yay
makepkg -si
# 安装完成后，可以使用 yay 命令来安装 AUR 软件包
# 使用 Yay 安装 AUR 软件包
yay -S 包名

# 例如，安装 Google Chrome 浏览器
yay -S google-chrome
```

## 文件系统快照

```bash
# 安装 snapper 及相关工具
# snapper -> 文件系统快照和回滚工具
# snap-pac -> 用于与 pacman 集成的 snapper 插件
# btrfs-assistant -> Btrfs 文件系统管理工具
# grub-btrfs -> 将 Btrfs 快照集成到 GRUB 启动菜单
# inotify-tools -> 文件系统事件监控工具
pacman -S snapper snap-pac btrfs-assistant grub-btrfs inotify-tools
# 启动并设置开机自启 grub-btrfsd 服务
systemctl enable --now grub-btrfsd

# 重启
reboot

# 创建名为 root 的快照配置，针对根目录 /
# -c -> 指定配置名称
# create-config -> 创建配置
snapper -c root create-config /
snapper -c home create-config /home
# 查看快照配置
snapper list-configs

# 创建快照
snapper -c root create -d "Hello Root"
snapper -c home create -d "Hello Home"
# 列出快照
snapper -c root list
snapper -c home list

# 安装 LTS 内核以提高系统稳定性
pacman -S linux-lts

# 将快照集成到 GRUB 启动菜单
grub-mkconfig -o /boot/grub/grub.cfg
```

## Hyprland

hyperland 是一个基于 Wayland 的动态平铺窗口管理器，灵感来自 i3 和 dwm，旨在提供高效且可定制的窗口管理体验。

[参考](https://www.bilibili.com/video/BV1wTsVzpET4)

[参考2](https://github.com/SHORiN-KiWATA/Shorin-ArchLinux-Guide/wiki/%E5%AE%89%E8%A3%85Hyprland)

### 安装必要组件

| 名称       | 功能                     |
| ---------- | ------------------------ |
| hyprland   | 窗口管理器核心           |
| ghostty    | 终端仿真器               |
| fuzzel     | 快速应用启动器           |
| firefox    | 网页浏览器               |
| wqy-zenhei | 文泉驿正黑字体，中文支持 |

```bash
# 安装 fish shell
pacman -S fish
chsh -s /usr/bin/fish

# 安装 Hyperland 及相关组件
# hyprland -> 窗口管理器核心
# kitty -> 终端仿真器
# fuzzel -> 快速应用启动器
# firefox -> 网页浏览器
# wqy-zenhei -> 文泉驿正黑字体，中文支持
pacman -S hyprland kitty fuzzel firefox wqy-zenhei

# 启动
hyprland
```

super + M 退出

### 编辑配置文件

```bash
vim ~/.config/hypr/hyprland.conf
# 修改终端为 ghostty
# terminal = ghostty
# 修改默认菜单
# menu = fuzzel

# 移除上方警告
# 删除 autogenerated = 1
```

```bash
# 配置分辨率和刷新率
# 列出显示器信息
hyprctl monitors all
# 编辑配置文件
vim ~/.config/hypr/hyprland.conf
# monitor=<显示器名称>,<分辨率>@<刷新率>,<X偏移>,<Y偏移>,<缩放>
# monitor=DP-1,1920x1080@60Hz,0,0,1

# 关闭鼠标加速
# 在配置文件中添加以下行
input "type:mouse" {
    accel_profile = flat # 关闭鼠标加速
}
```

设置重要程序开机运行

```bash
vim ~/.config/hypr/hyprland.conf
# 在配置文件中添加以下行
exec-once = mako
exec-once = /usr/lib/hyprpolkitagent/hyprpolkitagent
# 设置开机自动启动 Hyprland 的 XDG 桌面门户服务
```

编辑 mako 配置文件

```bash
mkdir -p ~/.config/mako
vim ~/.config/mako/config
```

```conf
# 写入
default-timeout=8000
border-radius=5
font=JetBarinsMono NEP 15
```

`default-timeout` 设置自动关闭时间，毫秒为单位，8000是8s

`border-radius` 圆角

`font` 字体和字体大小

重新加载配置文件

```bash
makoctl reload
```
