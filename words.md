# 术语速查

| 英文缩写 | 英文全称                              | 中文释义           | 解释                                                |
| -------- | ------------------------------------- | ------------------ | --------------------------------------------------- |
| GUID     | Globally Unique Identifier            | 全局唯一标识符     | 一种用于标识信息的 128 位整数，确保在不同系统中唯一 |
| UUID     | Universally Unique Identifier         | 通用唯一标识符     | 即 GUID，用于唯一标识信息的 128 位整数              |
| GPT      | GUID Partition Table                  | GUID 分区表        | 一种基于 GUID 的分区表格式，用于硬盘分区管理        |
| MBR      | Master Boot Record                    | 主引导记录         | 一种传统的硬盘分区表格式，包含启动信息和分区表      |
| EFI      | Extensible Firmware Interface         | 可扩展固件接口     | 一种计算机固件接口，支持更复杂的启动和硬件管理      |
| UEFI     | Unified Extensible Firmware Interface | 统一可扩展固件接口 | 一种现代计算机固件接口，替代传统 BIOS               |
| BIOS     | Basic Input/Output System             | 基本输入输出系统   | 计算机启动时初始化硬件并加载操作系统的固件接口      |
| GRUB     | GRand Unified Bootloader              | 大统一引导加载程序 | 一种多操作系统引导加载程序，支持多种文件系统和内核  |
| KVM      | Kernel-based Virtual Machine          | 基于内核的虚拟机   | Linux 内核模块，实现硬件虚拟化功能                  |
